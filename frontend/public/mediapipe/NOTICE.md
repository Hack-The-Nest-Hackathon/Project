This activity uses Google MediaPipe Tasks Vision 1.2.3, licensed under Apache License 2.0. The SDK JavaScript and WebAssembly files are copied from the pinned npm dependency during development/build preparation.

The bundled Gesture Recognizer model is Google's float16, version 1 model:
https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/1/gesture_recognizer.task

MediaPipe source and license: https://github.com/google-ai-edge/mediapipe
Google task documentation: https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer

See LICENSE in this directory. The game’s interpretations and lessons are authored game content; the model recognises hand shapes rather than intent or emotion.
